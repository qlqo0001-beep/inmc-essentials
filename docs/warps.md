# 워프(warps) — 운영 안내

CMI 의 setwarp · warp · editwarp · removewarp · warpgroups · config `Warps` · `Saves/Warps.yml` 을 대신한다.

- 저장: `plugins/inmc-essentials/warps.yml`(목록 — 고칠 때마다 원자적으로 통째로 씀). 읽지 못한 칸은 지우지 않고 그대로 되써 넣는다(서버 로그에 경고).
  **손으로 고쳤으면 바로 `/에센셜 리로드`** — 파일 시각이 우리가 마지막으로 쓴 때와 다르면 다시 읽는다(읽기는 I/O 워커, 끼우기는 메인 — 다른 리로드와
  같다). 리로드 전에 게임 안에서 워프를 고치면 메모리의 것으로 파일을 다시 써서 손으로 고친 것이 덮인다. 읽는 사이에 고쳤으면 반영하지 않고 서버 로그에
  남긴다 — 다시 리로드하면 된다.
- 설정: `settings/warps.yml`(`/에센셜 리로드`), 메시지: `messages/warps.yml`.

## 명령

| 명령 (영어 별칭) | 하는 일 | 권한 (기본) |
|---|---|---|
| `/워프` (warp, warps) | 워프 화면(`gui: false` 면 채팅 목록) | `inmcessentials.warps.use` (모두) |
| `/워프 <이름>` | 그 워프로 | `.use` + 권한이 필요한 워프면 아래 |
| `/워프 <이름> <플레이어> [-s]` | 남을 워프로(워프 권한 요구를 건너뜀). `-s` = 알리지 않음 | `inmcessentials.warps.others` (OP) |
| `/워프 그룹:<그룹> [쪽:N]` · `/워프 -g:<그룹>` · `/워프 쪽:N` | 그 그룹만 · N 쪽 | `.use` |
| `/워프설정 <이름> [true/false] [손\|머리\|머리:이름\|재질] [칸] [true/false] [그룹:이름\|-g:이름] [월드;x;y;z;yaw;pitch] [덮어쓰기]` (setwarp) | 선 자리(또는 적은 위치)에 워프. 첫 참/거짓 = 권한 필요, 둘째 = 자동 설명. 순서는 자유 | `inmcessentials.warps.set` (OP) · 좌표 지정은 `inmcessentials.warps.customloc` (OP) 또는 `.admin` |
| `/워프삭제 [이름]` (delwarp, removewarp) | 지우기. 이름 없이 치면 눌러서 지우는 목록 | `.set`(자기가 만든 것) · `.admin`(전부) |
| `/워프편집 <이름>` (editwarp) | 편집 화면 | `.set`(자기 것) · `.admin` |
| `/워프편집 <이름> <새 이름>` | 이름 바꾸기 | 위와 같음 |
| `/워프그룹` (warpgroups) | 그룹 화면(그룹마다 워프 수 — 누르면 그 그룹). 채팅이면 누르는 목록 | `.use` |

그 밖의 권한: `inmcessentials.warps.admin` (OP) 모든 워프 고치기·지우기·숨긴 워프 보기·개수 무제한 · `inmcessentials.warps.all` (OP) 권한 필요 워프 전부 ·
`inmcessentials.warps.customloc` (OP) `/워프설정` 에 좌표를 적어 선 자리가 아닌 곳에 만들기(만들기 권한만 준 사람 — 상점 워프 등 — 이 가 본 적 없는 남의 영지에
워프를 두지 못하게).
글자로 짓는 노드(선언돼 있지 않음 — op 는 저절로 가진다): `inmcessentials.warps.warp.<이름(소문자)>` 그 워프 쓰기(CMI `cmi.command.warp.[이름]`) ·
`inmcessentials.warps.limit.<숫자>` 만들 수 있는 워프 수(CMI `cmi.command.setwarp.[n]`, 없으면 `default-limit`, -1 = 무제한).

같은 이름이 있으면 채팅의 **[덮어쓰기]** 를 누르거나 `덮어쓰기` 를 붙인다(만든 사람·관리자만). 덮으면 적은 것만 바뀌고 그룹·아이콘·설명은 남는다.
`gui-on-creation: true` 면 새로 만든 직후 편집 화면이 열린다.

## 화면

- `/워프` — 54칸, 쪽당 45개. 전체 화면에서는 워프의 칸(slot)을 지킨다(1부터, 쪽을 넘어 이어짐), 그룹 화면은 이름순. 권한이 없는 워프는
  '권한 없어도 보이기' 가 켜져 있으면 잠긴 채(`locked-icon`), 아니면 안 보인다. 숨긴 워프는 관리자만 본다(이름을 아는 사람은 `/워프 이름` 으로 간다).
  고칠 수 있으면 Shift+우클릭 = 편집. 아래 줄: 그룹 · ◀ ▶ · 정보 · 여기에 새 워프(`.set`) · 닫기.
- `/워프그룹` — 전체 · 그룹들 · 그룹 없음. 관리자: 우클릭 = 그룹 이름 바꾸기(그 그룹의 워프 전부), Shift+우클릭 = 그룹 풀기(확인).
- `/워프편집` — 이름 · 여기로 옮기기 · 아이콘(손에 든 아이템의 **보이는 것만** — 재질·이름·설명 16줄·모델·반짝임·머리 주인 / 우클릭 = 기본) · 그룹 · 권한 필요 ·
  권한 없어도 보이기 · 숨김 · 보이는 이름(MiniMessage) · 설명(여러 줄) · 자동 설명(월드·좌표·그룹) · 화면 칸 · 도착 방향 무작위 · 추가 위치(클릭 = 선 곳 더하기,
  Shift+우클릭 = 모두 지우기 — 이동할 때 기본·추가 위치 중 무작위) · 가 보기(관리자는 바로, 만든 사람은 `/워프 이름` 과 같은 규칙) · 지우기(확인).
  누를 때마다 지금의 워프를 다시 읽어 고친다 — 그 사이 다른 관리자가 지웠거나 이름을 바꿨으면 알리고 아무것도 쓰지 않는다.
- 아이콘으로 셜커 상자·꾸러미·책을 들어도 **안의 내용은 저장하지 않는다**(워프 화면을 여는 모두에게 큰 패킷이 가는 것 — 책 밴 — 을 막으려고). 옛 판이 통째로
  적어 둔 아이콘도 읽을 때 같은 것만 남긴다.

화면에서 누른 이동은 **`/워프 이름` 을 친 것과 같다** — commands 기능의 대기·쿨타임·비용이 명령 이름 `워프` 로 걸린다(화면을 `/워프그룹` 으로 열었어도).
대기·쿨타임·비용은 commands 기능 설정에서 명령 이름으로.

## 부활 워프

`/스폰 관리` 의 '부활 워프' 에 워프 이름을 정하고 부활 순서의 '부활 워프' 칸을 켜면 죽은 사람이 그 워프로 부활한다(권한·숨김 무시 — CMI `warp!이름`).
워프 이름을 바꾸면 부활 워프도 따라 바뀐다. 지우면 지운 사람에게 알리고 그 칸은 건너뛴다(관리 화면에 빨갛게, `/에센셜 검증` 이 잡는다).

## CMI 가져오기

`/에센셜 가져오기 cmi`(server 기능)가 CMI 워프(이름·위치·그룹·권한 필요·아이콘)를 넣는다. 같은 이름이 있으면 건너뛴다. 이름이 `name-pattern`·길이에
맞지 않으면(빈칸·따옴표 등) 못 쓰는 글자를 `_` 로 바꿔 넣고 보고서에 남긴다. 권한이 필요한 워프는
보고서에 새 권한 노드(`inmcessentials.warps.warp.<이름>`)를 남긴다 — LuckPerms 에서 바꿔 줄 것. 옮기지 못한 CMI 속성(보이는 이름·설명·슬롯·꺼짐 아이콘 등
CmiWarp 에 없는 것)은 보고서에 이름을 남긴다. (테섭 CMI `Saves/Warps.yml` 은 비어 있다.)

## CMI 와 다른 점

- 이름 최소 길이 기본 1(CMI 4) — 한글 이름이 짧아서.
- 화면 쪽마다 다른 제목(pageTitles)·닫기/정보 버튼 설정·쪽 크기(perPage)·워프마다 쪽 번호·꺼짐 아이콘(off icon)·BlueMap 마커·화면 여는 소리는 없다.
  쪽은 45칸 고정, 칸 번호가 쪽을 넘어 이어진다.
- 추가 위치는 늘 무작위(CMI 의 '반복 위치' 켜고 끄기 없음).
- 머리 아이콘(`머리:이름`)은 이 서버에 온 적 있는 사람만(이름으로 웹을 찾지 않는다).
