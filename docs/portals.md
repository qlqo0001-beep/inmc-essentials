# 포탈(portals) — 운영 안내

CMI 의 `/cmi portals`(new · nearest · forceupdate · setlocation · enabled) · `/cmi select` · config `Portals` · `Saves/Portals.yml` 을 대신한다.

- 저장: `plugins/inmc-essentials/portals.yml`(고칠 때마다 원자적으로 통째로 씀). 읽지 못한 칸은 지우지 않고 그대로 되써 넣는다(서버 로그에 까닭과 함께 경고).
  `max-volume` 을 넘거나 좌표가 월드 경계(±30,000,000 · 높이 -4096~4096) 밖이거나 청크 65,536개(256×256)를 넘게 걸치는 영역도 **읽지 않고 남긴다** —
  손으로 자릿수를 하나 더 치면 청크 색인을 메인에서 짓다 서버가 멈추므로.
- `/포탈 다시읽기` 도중 누가 포탈을 고치면 그 고침을 잃지 않게 다시 읽는다(최대 세 번 — 그래도 겹치면 메모리를 그대로 둔다).
- **YAML 문법이 깨진 `portals.yml`**(손으로 고치다 들여쓰기·탭 실수)은 빈 것으로 읽지 않는다. 파일은 그대로 두고 옆에 `portals.yml.broken-<시각>` 사본을
  남기고, 서버 로그에 까닭을 남긴 뒤 **저장을 잠근다** — 잠긴 동안 고치는 명령·편집 화면·CMI 가져오기는 거절된다(저장하면 빈 것으로 덮어 모든 포탈이
  사라지므로). 켤 때 깨졌으면 포탈이 하나도 돌지 않고, `/포탈 다시읽기` 때 깨졌으면 지금 포탈을 그대로 쓴다. 파일을 고치고 `/포탈 다시읽기` 가 성공하면 풀린다.
- 읽지 못한 칸(`target`·`safe` 가 있는데 모양이 틀림 · 영역 등)과 **같은 이름(대소문자 무시)으로는 새 포탈을 만들지 않는다** — 되써 넣을 원문을 덮지 않게.
- 설정: `settings/portals.yml`(`/에센셜 리로드`), 메시지: `messages/portals.yml`. DB 는 쓰지 않는다.

## 만드는 법

1. 영역 고르기 — `/포탈 위치1` · `/포탈 위치2`(선 블록)로 두 모서리를 찍었으면 **그것이 먼저**, 아니면 **WorldEdit/FAWE 선택**(`//wand`).
   찍은 두 모서리는 만들기·다시 정하기가 성공하면 지운다(오래된 것이 다음 포탈에 쓰이지 않게). 완료 메시지에 어느 쪽을 썼는지 나온다.
2. `/포탈 만들기 <이름>` — 새 포탈은 설정의 `defaults` 를 받는다(목적지 없음 · 기본 효과 실명 2초 · 쿨타임 2초 · 소리).
3. 목적지 — 갈 자리에 서서 `/포탈 목적지 <이름>`(채팅의 **[여기를 목적지로]** 도 된다). 목적지가 없으면 명령·효과만 돈다(`목적지 없이 명령` 이 켜져 있을 때).
4. 나머지는 `/포탈 편집 <이름>` 화면에서.

## 명령 — 전부 `inmcessentials.portals.admin` (OP)

**`admin` 만으로는 콘솔 명령을 더하거나 바꿀 수 없다** — 콘솔 명령(`player:` 가 없는 줄)은 콘솔 권한과 같아서 `inmcessentials.portals.console`(OP)이
더 있어야 한다. 없으면 `player:` 명령만 더할 수 있고, 이미 있는 콘솔 명령은 지우거나 순서를 바꿀 수만 있다(편집 화면에서 글을 고쳐도 거절).
빌더에게 포탈을 맡길 때는 `admin` 만 주고 `console` 은 주지 말 것.

| 명령 (영어) | 하는 일 |
|---|---|
| `/포탈` · `/포탈 목록` (portals · list) | 목록 화면(가까운 순). 클릭 = 편집, Shift+우클릭 = 포탈로 이동. 콘솔이면 채팅 목록 |
| `/포탈 위치1` · `위치2` (pos1 · pos2) | 선 블록을 모서리로(둘 다 찍으면 WorldEdit 선택보다 먼저) |
| `/포탈 만들기 <이름>` (new) | 지금 선택으로 만들기. 다른 포탈과 겹치거나 `max-volume`·월드 경계·청크 상한을 넘으면 거절 |
| `/포탈 영역 <이름>` (redefine) | 영역을 지금 선택으로 다시 정하기(같은 검사) |
| `/포탈 목적지 <이름> [여기\|월드;x;y;z;yaw;pitch\|x y z\|지우기]` (setlocation) | 목적지. 비우면 선 자리. `:` 구분(CMI 모양)도 받는다 |
| `/포탈 안전위치 <이름> [여기\|…\|지우기]` (safeloc) | 권한이 없어 막힐 때 보낼 자리(없으면 밀어낸다) |
| `/포탈 켜기\|끄기 <이름>` (enable · disable) · `/포탈 켜고끄기 <이름>` (enabled) | 켜고 끄기. 꺼진 포탈은 그냥 영역 |
| `/포탈 가까이` (nearest) | 가장 가까운 포탈과 정보 |
| `/포탈 정보 <이름>` (info) · `/포탈 편집 <이름>` (edit) · `/포탈 삭제 <이름>` (remove) | |
| `/포탈 이동 <이름> [목적지]` (tp) | 포탈(또는 목적지)로 가 보기 — 관리 이동(ADMIN). 성공하면 `/포탈` 의 쿨타임(commands 기능) |
| `/포탈 명령 <이름> [추가 <명령>\|삭제 <번호>\|비우기]` (commands add/remove/clear) | 명령 보기·더하기·지우기 |
| `/포탈 다시읽기` (forceupdate) | `portals.yml` 을 다시 읽기(손으로 고친 뒤) |

## 들어서면

- **걸음마다 블록이 바뀔 때만** 본다(같은 블록 안 움직임·고개 돌리기는 바로 돌아간다). 그다음은 청크 색인으로 **그 청크에 걸친 포탈만** 본다.
  한 걸음에 1블록 넘게 가도(겉날개·급류·속도·지연) **지나간 블록을 다** 본다(한 걸음에 64블록까지) — 얇은 벽 포탈을 건너뛰지 않는다.
  CMI 는 300ms 마다 훑었다(`CheckInterval`) — 빨리 지나가면 놓칠 수 있었다.
- 걷기 사건은 둘로 나눈다. **HIGHEST** 에서 쓸 수 없는 포탈(밀어내기 켜짐)로 들어서는 걸음을 취소하고 밀어낸다. **MONITOR**(끝까지 취소되지 않은
  걸음만)에서 이동·명령·효과. 그래서 WorldGuard 출입 금지·Lands 처럼 다른 플러그인이 걸음을 막으면 포탈은 쏘지 않는다.
- **탈것**(광산 수레·보트·말·돼지·스트라이더 …)을 탄 사람은 걷기 사건이 오지 않으므로 탈것의 움직임(`VehicleMoveEvent`)으로 같은 판정을 한다 —
  선로·보트·말 포탈이 CMI 처럼 돈다. 탈것의 움직임은 취소할 수 없어 권한이 없으면 **탈것을** 왔던 쪽으로 민다(안전 위치가 있으면 사람을 그리로 —
  이동이 내려 준다). 이동은 사람만 옮긴다(탈것에서 내린다 — teleport 기능이 탑승 동반을 하면 그것을 따른다).
- 들어서는 순간 한 번만 쏜다. 안에서 걸어도 다시 쏘지 않고, 나갔다 들어오면 다시 쏜다. **도착으로 포탈 안에 선 것은 쏘지 않는다**(연쇄 막기) —
  순간이동 · 네더/엔드 포탈 이동 · 부활 · 월드 바꿈 · 접속 모두 "이미 안에 있음" 으로만 적는다.
- 순서: 권한 → 쿨타임 → 목적지로 이동(`ess.teleporter`, 종류 PORTAL — teleport 기능의 안전 자리·뒤로 기록 등을 탄다) → **이동이 성공하면** 효과·소리·명령.
  이동이 거절되면(감옥·던전·안전 자리 없음 등) 효과도 쿨타임도 남기지 않고 알린다. 목적지가 없으면 효과·명령만(`목적지 없이 명령` 이 꺼져 있으면 아무것도).
  **이동이 끝나기 전에는 다시 들어서도 쏘지 않는다**(청크를 읽는 동안 나갔다 들어와도 — 쿨타임 0 인 보상 포탈의 명령이 두 번 돌지 않게).
- 명령: 한 줄에 하나. `player:` 로 시작하면 그 사람이, 아니면 콘솔이 친다(CMI `asPlayer!`/`asConsole!` 도 읽는다). `{player}` · `[playerName]` · `{포탈}` · PAPI(그 사람 기준).
- 효과: `효과:초:레벨`(예 `blindness:2:1`, 레벨 1부터). 소리: `entity.enderman.teleport` 처럼 열쇠(비우면 없음).
- 권한이 없으면: `권한 없음 알리기` 가 켜져 있으면 알리고(막힌 채 계속 걸어도 1.5초에 한 번), `밀어내기` 가 켜져 있으면 **걸음을 취소한 뒤**
  안전 위치로 보낸다(있으면 — 그 이동이 거절되면 밀기로). 안전 위치가 없으면 왔던 쪽으로 민다(`push-strength`).

## 편집 화면

켜짐 · 권한 필요 · 밀어내기 · 권한 없음 알리기 · 목적지 없이 명령 · 쿨타임 · 효과·소리 / 파티클 켜기 · 종류(+DUST 색) · 수 · 자리(영역 전체·윗면·아랫면·가운데 높이) ·
면 줄이기 % · 보이는 거리 · 권한 없어도 파티클 / 명령(여러 줄) · 목적지(클릭 = 선 자리, 우클릭 = 지우기) · 안전 위치 · 영역 다시 정하기 · 포탈로 이동 · 목적지로 이동 · 지우기(확인).

파티클은 `particle-seconds` 마다(기본 1초 — 반복 작업이 돈 횟수로 센다, 렉에 벽시계가 밀려도 건너뛰지 않는다) **보이는 거리 안의 사람에게만** 그 사람에게 보낸다. 종류는 데이터가 필요 없는 파티클과 DUST(색)만 받는다 —
편집 화면에 없는 이름·데이터가 필요한 이름(BLOCK 등)을 치면 알리고 그대로 둔다(옛 이름 `reddust`·`witchMagic` 같은 것은 지금 이름으로 바꿔 받는다).
설정의 `defaults.particles.type` 이 쓸 수 없는 이름이면 켤 때 로그에 알리고 PORTAL 로 쓴다.

## 설정 (`settings/portals.yml`)

| 열쇠 | 기본 | 뜻 (CMI) |
|---|---|---|
| `particle-seconds` | 1 | 파티클 주기(초) — `CheckParticleInterval` 500ms. 우리 반복 작업은 1초 단위 |
| `push-strength` | 0.6 | 밀어내는 세기(0 = 걷기 취소만) |
| `max-volume` | 200000 | 한 포탈의 최대 블록 수 — 만들 때와 **`portals.yml`·CMI 를 읽을 때** 모두. 줄이면 그보다 큰 기존 포탈은 읽지 않고 남는다(로그) |
| `defaults.commands-without-target` | true | `Defaults.PerformCommands` |
| `defaults.commands` | [] | `Defaults.Commands` |
| `defaults.effects` | [blindness:2:1] | CMI 기본 명령 `cmi effect [playerName] blindness 2 1 -s` 를 명령 없이 |
| `defaults.cooldown-seconds` · `sound` · `kick-back` · `inform-permission` · `particles.{enabled,type,amount,range}` | 2 · entity.enderman.teleport · true · true · … | 새 포탈의 값 |

## CMI 가져오기

`/에센셜 가져오기 cmi`(server 기능)가 `Saves/Portals.yml` 을 넘기면 읽는다(jar `PortalManager.save` 로 확인한 모양 — `<월드>.<포탈>.Loc/Tp/safeLoc/...`).
같은 이름이 있으면 건너뛴다. 이름의 점·빈칸은 `_` 로 바꾼다. 권한이 필요한 포탈은 새 노드를, CMI 명령(`cmi …`)이 든 포탈은 고치라고 보고서에 남긴다.

- 영역을 못 읽거나 `max-volume`·월드 경계·청크 상한을 넘는 포탈 · 모르는 속성은 `못 읽음` 으로 남는다(넣지 않는다).
- **이미 있는 포탈 또는 이번에 넣는 포탈과 영역이 겹치면 건너뛴다**(보고서에 `건너뜀` — 겹친 자리에서는 이름순 첫째만 쏘므로, 만들기와 같은 규칙).
  `portals.yml` 에 같은 이름의 못 읽은 칸이 있어도 건너뛴다. `portals.yml` 이 깨져 잠겼으면 아무것도 넣지 않는다.
- CMI 가 **기본값이면 파일에 쓰지 않는** 열쇠는 CMI 기본값으로 읽는다(`CMIPortal` 생성자 — javap): `informOnMissingPerm` 없음 = 알리지 않음,
  `particleAmount` 없음 = 10(`effect` 의 `a{N}` 이 있으면 그것), `activationRange` 없음 = 16. 그래서 가져온 포탈은 CMI 와 같게 돈다.
- 명령 속 `[playerName]`·`[playerDisplayName]` 은 `{player}`(이름 — 표시 이름이 아니다, 알린다). 그 밖의 CMI 변수(`[world]` 등 소문자로 시작하는 `[낱말]`)와
  `%cmi_…%` PAPI 는 CMI 를 빼면 글자 그대로 들어가므로 포탈마다 알린다.
- CMI 기본 명령 `cmi effect [playerName] <효과> <초> <배수> [-s]` 는 **효과 한 줄**(`효과:초:레벨`)로 바꿔 넣는다 — CMI 를 빼도 돈다.
- `asPlayer!`/`asConsole!` 밖의 CMI 특수 접두(`delay!` · `chance!` 등)는 알린다(그대로 콘솔 명령이 되어 실패한다).
- 파티클 `effect` 는 CMILib 모양(`RedDust;a{3};s{0.1}`)에서 이름을 지금 Bukkit 이름으로 바꾸고(`reddust` → DUST, `witchMagic` → WITCH …) `a{N}` 을 수로 쓴다.
  못 알아보면 PORTAL 로 넣고 알린다. 색(`color`)은 DUST 의 색.

**테섭 CMI 의 `Saves/Portals.yml` 은 비어 있어 실제 표본으로 검증하지 못했다.**

## CMI 와 다른 점

- 번지 서버 이동(`bungeeServer` · `bungeeLocation` · `exactBungeeLocation`)은 없다 — 가져올 때 알린다.
- "나가면 명령 대기 취소"(`cancelWarmup`)는 없다 — 대기는 commands 기능 몫이고 포탈은 명령 대기를 걸지 않는다.
- 파티클 크기(`size`)는 없다. 파티클 주기는 1초가 가장 짧다(CMI 500ms). 데이터가 필요한 파티클은 DUST(색)만.
- 탈것(`Vehicle` — 수레·보트·말·돼지 …)은 판정한다. 그러나 `Vehicle` 이 아닌 것에 탄 사람(다른 플레이어 위 `/타기` · 플러그인이 태운 몹)은 판정하지 않는다
  (그 움직임에는 사건이 없다 — CMI 는 300ms 마다 훑어 잡았다).
- 들어서기 판정은 주기 대신 걸음마다(지나간 블록까지 — 더 정확하다). 쿨타임·효과 목록·소리는 CMI 에 없던 것(CMI 는 기본 명령으로 실명을 걸었다).
- 선택 도구는 WorldEdit 그대로(우리 지팡이 없음) + `/포탈 위치1·2`. CMI `/cmi select` 의 shift/expand/contract 는 WorldEdit 명령을 쓴다.

## 검증기 (`/에센셜 검증`)

portals.yml 을 다 읽었다(깨져 잠겼는지 · 못 읽은 칸과 까닭) · 청크 색인 · 들어서면 명령(진짜 걷기 사건) · 안에서 걸어도 다시 안 쏨 · **권한을 메모리에서 잠깐 빼고**(붙임 — op 도) 걷기 취소·명령 안 돎 ·
포탈 노드가 있으면 씀 · 한 걸음에 3블록 가도 얇은 포탈을 쏨 · 다른 플러그인이 취소한 걸음에서는 안 쏨 · 꺼진 포탈은 아무것도 안 함 ·
**순간이동으로 포탈 안에 도착하면 안 쏨**(진짜 순간이동 사건 — 실제로 옮기지 않는다) · **쿨타임 안에 다시 들어서면 안 쏨**(bypass 를 붙임으로 잠깐 뺀다) ·
**탈것을 탄 채 들어서도 쏨**(진짜 `VehicleMoveEvent` — 검사자를 잠깐 저장 안 되는 수레에 태웠다 내리고 수레를 지운다. 이미 무언가를 탔거나 관전 모드면 건너뛴다).
명령은 실행하지 않고 모으기만, 포탈은 메모리에만.
